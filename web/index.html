Settings

Mode

Guest (built-in library · 30s previews)
Storefront:

The same library Apple shipped with the iPod easter egg (2001/2000s hits + "Songs From iPod Ads").

Local Music (offline, full tracks)
Not scanned

Fixed library folder: /sdcard/Music (subfolders included). MP3 / M4A / FLAC / OGG / WAV. ID3 tags are read automatically, artists grouped, .m3u playlists imported. First scan asks for storage permission.

Apple Music (experimental)
Not signed in

Needs an Apple Developer token (see README). Full playback requires an Apple Music subscription; falls back to 30s previews otherwise.

Appearance

Switching appearance reloads the page.

How to use
  • Wheel: drag the inner ring to scroll (adjusts volume on Now Playing); outer band = Menu / Back / Forward / Play-Pause; center = Select
  • E-Ink tip: on lists, tap the inner ring to step the selection — upper half = up, lower half = down (dragging still scrolls); the outer buttons keep their original functions
  • Keyboard (desktop): ↑↓ navigate, Enter select, Esc back/settings
  • Hold Menu: toggle backlight (Original mode only)
  • Settings → About → hold Select for 5s: unlock Brick
  • Press the Back key anytime to open Settings
